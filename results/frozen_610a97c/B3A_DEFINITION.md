# B3-A(비대칭 기각) 정의 — 보조 구성, Holm 대상 아님 (연구자 결정 2026-11-27, 정책 고정 뒤·v4b 실행 전, 조정 22)

- 주 결과는 고정된 B3다. B3-A는 고정 이후 사전 선언한 보조 구성으로 따로 보고한다.
- 정의: B3(고정 `cdv/v2/m1g_path.py::run_m1g_path`, 선택적 재확인, 미검증 조건 정책)와 같다. 규칙 하나만 다르다:
  - M1-G가 "question" 또는 "not_mentioned"로 판정해 REJECT가 된 변경 가운데 **권한을 좁히는 변경**은 기각하지 않는다.
  - 대신 미확정 항목(변형: 이전 값 유지 / 변경 반영, 종류 `M1G_REJECT_NARROWING`)으로 둔다. "ambiguous"와 같은 처리다.
  - 사용자 턴이 없는 단계의 변경은 B3와 같이 기각한다.
- 좁히는 변경(필드별 결정적 규칙, `eval/aux_arms/b3a.py::narrows`):

| 필드 | 좁힘으로 보는 경우 |
|---|---|
| 예산(budget_max) | 새로 생김, 또는 값이 낮아짐 |
| 기한(deadline_days) | 새로 생김, 또는 값이 짧아짐 |
| 제외 브랜드(brand_out) | 새로 생김, 또는 집합이 엄격히 커짐 |
| 허용 브랜드(brand_in) | 새로 생김, 또는 집합이 엄격히 작아짐 |
| 수령 방식(fulfillment) | 새로 생김 |
| 대체 허용(substitute) | 철회(없어짐) |
| 그 밖(수량, 묶음, 조건 삭제, 값 바꾸기) | 좁힘 아님 |

- 호출: M1-G 요청은 추출 상태로만 정해지므로 B3와 같다. 해당 실행의 원장을 재생해 계산하며, 추가 호출은 0이다(원장에 없는 요청은 보내지 않고 센다).
