- 스크립트: `eval/e_m1/recompute_truncated.py` → `corrected_truncation/`(TABLES.md, summary.json, rows.jsonl). 원 결과 파일은 고치지 않았다.
- 판정 시점: 마지막 결제 동의 요청 직전 / 결제 단계가 없으면 첫 `done` 직전. FnCTOD 세 팔만 저장된 턴별 상태로 다시 판정했다(run.py와 같은 규칙, NLI, 결정 우선순위 CLARIFY > M2a, 알려진 브랜드는 절단된 상태에서 만듦). 일반 LLM 팔은 재추출 전까지 원(누설) 값만 표시한다.
- **첫 실행 오류(버림):** R2 여정은 네 분할(train·validation·test_cross_store·test_cross_template)에서 뽑았는데, 첫 실행은 대화를 test_cross_store에서만 읽었다. R2의 대부분 여정에서 대화가 비어 판정 시점이 0이 되었고, 모든 판정이 DENY로 나왔다(R2 '판정 변경' 71/85/86). 이 결과는 커밋하지 않았고, 재실행 출력으로 덮어써 버렸다.
